# Архитектура проекта

Проект разделён на независимые игровые данные, игровую логику и представление.

- `core/` — модели и логика без зависимости от конкретного UI.
- `data/` — настраиваемые Godot Resources с параметрами GDD.
- `ui/` — сцены и скрипты представления; UI получает данные через ресурсы.
- `tests/` — headless-проверки моделей, ресурсов и сцен.

Стартовая сцена — `res://ui/main/main.tscn`. Логический viewport зафиксирован как
960×540 (16:9), а интерфейс растягивается в режиме `canvas_items` с аспектом
`expand`. Основной экран заранее разделён на области поля, результата хода и боя
в пропорции 60/8/32 из GDD.

Игровые константы нельзя хранить в UI-узлах. Они задаются в
`res://data/game_rules.tres` на основе класса `GameRules`, поэтому будущие игровые
системы и headless-тесты могут использовать один источник параметров.

Модель поля находится в `core/board/`. `BoardModel` хранит состояние клеток и
предоставляет запросы к нему, а `BoardGenerator` создаёт стартовую раскладку по
весам `GameRules`. Генератор можно инициализировать seed, что делает сценарии
воспроизводимыми в тестах и будущих симуляциях баланса.
